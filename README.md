## GPU 云服务究竟是什么

它是 NVIDIA GPU 算力的租赁服务。提供商拥有硬件——部署在具有冗余电源、冷却和网络上行链路的数据中心的企业级服务器——并出租其时间。你提交一个指定 GPU 型号和数量的请求，平台的调度程序找到一个匹配的节点，用你选择的操作系统镜像进行预配置，并返回 SSH 凭证。计费在实例启动时开始，并在你终止它时停止，在按需方案中通常按秒或分钟计费。

存在两种硬件模式。裸金属（Bare metal）为你提供整个物理服务器；虚拟化则为你提供一台在共享主机上拥有专用 GPU 资源的虚拟机。大多数 AI 工作负载更喜欢裸金属，因为虚拟化会增加延迟并限制驱动程序访问。在像 H100 SXM 配置这样的多 GPU 节点上，NVLink 以每个 GPU 900 GB/s 的速度将显卡连接起来，这对于任何在训练期间在 GPU 之间移动激活值（activations）的任务都很重要。

## 为什么普通的云服务器无法胜任

矩阵运算是原因。神经网络训练是数十亿个并行运行的小型乘加运算，而 GPU 正是为这种形状的工作而构建的。现代 NVIDIA B200 拥有 10,752 个 CUDA 核心和 3.35 TB/s 的 HBM3e 内存带宽。高端 CPU 服务器的上限约为 192 个核心和大约 400 GB/s 的 DDR5。这种差距决定了你的训练任务是花费 20 分钟还是两天。

实际的经验法则是：任何导入 PyTorch、JAX 或 CUDA 的程序都适合放在 GPU 上。数据管道、Web 服务器和 API 粘合代码在普通的 CPU 实例上运行良好，而且将它们留在那里通常更便宜。

## 你的模型需要多少 VRAM

显存（VRAM）是决定你需要哪种方案的限制，模型大小设定了 GPU 必须满足的底线。一个 7B 参数的模型需要大约 14 GB，24 GB 的显卡可以轻松处理——RTX 4090 级别的显卡提供该模型大约 40-60 tokens/s 的推理速度。70B 模型在 FP16 下需要大约 140 GB，这意味着你需要一块 141 GB 的 H200 级别显卡，或者拆分到两块 80 GB 的显卡上——或者使用 QLoRA 进行微调，这可以将 70B 任务压缩到单个 A100 80GB 上。在极端情况下，单个 192 GB 的 B200 可以以 FP8 运行 405B 模型。

考虑检查点的大小：FP16 下的 13B 模型大约是 26 GB，该检查点的每次下载都会跨越我们上面介绍的出口定价。

## 常见问题

### 最便宜的市场列表对于生产工作安全吗？

这取决于折扣买到了什么。Vast.ai 的未经验证的社区主机列出的 H100 SXM 起价约为 0.90 美元/小时，而有文档记录的数据中心主机运行价格为 1.50–1.87 美元/小时——差距在于信誉和可追溯性的价格。RunPod 按层级显示了相同的划分：Community Cloud 以 1.99 美元/小时的价格租用 H100 PCIe 且无 SLA，而 Secure Cloud 对有 SLA 保障的硬件收费 2.89 美元/小时。批量作业和实验可以追求便宜货；任何面向客户的程序都应该建立在有 SLA 保障的基础设施上。

### 训练需要裸金属吗？

除了轻度工作，是的，最好选择裸金属。虚拟化会增加延迟并限制驱动程序访问，这对于单 GPU 推理来说还可以，但对于多 GPU 训练来说就很烦人了。裸金属或专用直通消除了这两个问题。

### 额外费用隐藏在哪里？

出口流量和存储。出口流量在超大规模服务商处为 0.09–0.12 美元/GB，而在大多数自助式云中为零。存储在一些平台上是分开计费的，费率如 RunPod 容器磁盘的每月 0.10 美元/GB。在部署之前，这两者都是任何提供商价格页面上的单行检查项。
